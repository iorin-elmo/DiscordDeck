GETTING STARTED

DiscordDeckの使い方

  1. アカウントを追加

    表示名を決め、列内のDiscord公式画面でログインします。

  2. 自分の見やすい並びに

    2列・3列・4分割・単独表示を切り替えられます。左バーをドラッグすると並び順を変更できます。

  3. 倍率・色・アイコンを調整

    列の「…」で表示倍率、カラーコード、アイコン、通知や通話の許可を変更できます。

  4. サーバー・DMに移動

    列の左上のメニューから移動します。一覧にない移動先は「Discordの元の一覧・上部バーを表示」から開けます。統合表示は「…」で切り替えられます。

最大8アカウント。未読マークはDiscordの未読表示に連動します。自動アイコンや統合表示はDiscordの画面変更により取得できない場合があります。

通話はDiscord内の通話ボタンから開始し、マイクの確認で許可してください。カメラは「…」で有効にします。画面共有は未対応です。
